# aso-research/

Canonical store for ASO deep research outputs. Every research session creates a new dated folder.

## Structure

```
aso-research/
├── README.md                   ← this file
└── YYYY-MM-DD/
    ├── SYNTHESIS.md            ← MUST READ FIRST — convergent + divergent insights
    ├── gemini-*.md             ← Gemini Deep Research transcripts (real research data)
    └── chatgpt-*.pdf|.md       ← ChatGPT Deep Research outputs (often methodology-focused)
```

## Rule

Before any ASO strategy decision or `/aso-refresh` skill change:

1. List `aso-research/` to find latest dated folder.
2. Read `SYNTHESIS.md` from latest folder.
3. Cite specific claims by file + section, not from memory.

## Why this exists

Past sessions kept re-deriving the same cadence/tools questions. Each research run was ephemeral. Now permanent.

Linked from `MEMORY.md` via the [ASO cadence LOCKED 14/30] entry → `aso_cadence.md`.
